# Lumiera

The baseline repository for **Lumiera**: science explained visually, as short vertical films for
TikTok, Instagram Reels and YouTube Shorts. *The universe, drawn in light.*

| | |
|---|---|
| [`playbook/`](playbook/README.md) | **Start here.** The style and brand guide every agent and person follows: film style, brand and voice, idea backlog |
| [`doubling_film/`](doubling_film/README.md) | *The Doubling*: Planck length → observable universe in 205 doublings. The reference film, built with Manim |
| [`shuffle_film/`](shuffle_film/README.md) | *The Long Number* (working title *The Shuffle*): a typeset ledger of the possible deals as cards are dealt from a full deck, against the seconds since the Big Bang. The second film, rendered with Canvas 2D in headless Chromium via Playwright; see its README |
| [`lumiera_brand/`](lumiera_brand/README.md) | Logo and brand assets (generated from code), profile texts, launch-post package |
| `archive/` | Earlier material, kept for reference |
| [`archive/shuffle_film_manim/`](archive/shuffle_film_manim/README.md) | The superseded first build of the second film (Manim, on The Doubling's engine), kept as a record |

AI agents: see [`AGENTS.md`](AGENTS.md). `CLAUDE.md`, `GEMINI.md` and `.github/copilot-instructions.md`
point to the same rules.
