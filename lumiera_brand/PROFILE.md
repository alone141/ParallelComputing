## Handle

1. **Try `@lumiera` first** on TikTok, Instagram and YouTube. The account name is Lumiera, so the plain handle is the best choice wherever it is free.
2. If it is taken anywhere, use **`@lumiera_science`** on all three, so people can find you with one handle.
3. Backups, in order: `@lumierascience`, `@lumiera.explained`, `@lumiera_explained`.

> Avoid `@lumiera.science`. YouTube rejects handles that look like a web address, and `.science` is a real domain ending.

| Rule | TikTok | Instagram | YouTube |

## Link in bio

Use one link on all three profiles: a simple **"Start here"** page (Linktree, Beacons or similar, in the same dark style). Keep it to three or four buttons:

1. **Watch The Doubling**: the YouTube Short.
2. **Ask Lumiera a question**: a short form. The answers become future videos and comment replies.
3. **Lumiera on TikTok · Instagram · YouTube**.
4. *(Optional)* **The numbers**: a plain page listing the sizes and sources behind each video (the README in `doubling_film/` has the full table).

Platform notes:
- TikTok shows a clickable bio link on personal accounts only from about 1,000 followers, so the TikTok bio works without one.
- On YouTube, links in Shorts descriptions aren't clickable. Put the link in the channel's *Links* section.
- If the domain `lumiera.science` is free, it's worth registering. Test that the platforms' link filters accept it before relying on it.
